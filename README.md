# Superstore Sales Data Analysis

## Overview

This project analyzes the Kaggle Superstore dataset to uncover sales trends, profitability drivers, customer behavior, and regional performance. The analysis covers data cleaning, exploratory data analysis (EDA), visualization, and business recommendations to support data-driven decision-making.

## Key Metrics

| Metric              | Value     |
| ------------------- | --------- |
| Total Sales         | $14.92M   |
| Total Profit        | $1.52M    |
| Profit Margin       | 10.20%    |
| Total Orders        | 5,496     |
| Average Order Value | $2,713.90 |

## Key Insights

* **Technology** is the top-performing category, generating the highest sales and profit.
* **Furniture** underperforms, with Tables and Bookcases contributing to losses.
* The **West Region** leads in sales performance, while the **Central Region** shows the weakest profitability.
* Sales peak during **November–December**, highlighting strong seasonality.
* The **Corporate Segment** generates the highest revenue among customer segments.
* Discounts above **15%** significantly reduce profitability and often result in losses.

## Recommendations

* Increase focus on high-performing Technology products.
* Review pricing and cost structures for loss-making Furniture items.
* Apply successful West Region strategies to lower-performing regions.
* Optimize discount policies to protect profit margins.
* Strengthen engagement with Corporate customers through targeted campaigns.
* Improve inventory planning for peak sales periods.
